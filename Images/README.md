# Images — Dashboard Screenshots

This folder contains screenshots of the Power BI dashboard built for the **Fraud Transaction Detection** project. These are referenced in the main [project README](../README.md) 

---

## 📸 Contents

| File | Description |
|---|---|
| `page1_fraud_risk_patterns.png` | Page 1 of the dashboard — exploratory fraud pattern analysis (fraud rate by age group, category, hour of day, and average fraud vs. legit transaction amount) |
| `page2_model_performance.png` | Page 2 of the dashboard — machine learning model evaluation (KPI cards, confusion matrix, threshold comparison table, ROC curve) |



## 📝 Notes

- These are static exports of the interactive `.pbix` dashboard  Filters, slicers, and drill-throughs are only functional when the file is opened in Power BI Desktop.
- If you update the dashboard, re-export fresh screenshots here (File → Export → Export as image, or a simple screenshot) and keep the filenames consistent so the links in the other READMEs don't break.
